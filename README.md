# Ritvara

Ritvara este o aplicație iOS pentru organizarea activităților, formarea rutinelor și urmărirea progresului personal.

## Funcționalități

- activități cu adăugare, editare, ștergere și status;
- rutine recurente și progres zilnic/săptămânal;
- obiective, jurnal și statistici;
- notificări configurabile și Live Activity;
- căutare, filtre, backup și restaurare;
- interfață în română și engleză.

## Tehnologii

Swift, SwiftUI, SwiftData, UserNotifications, ActivityKit și Xcode.
