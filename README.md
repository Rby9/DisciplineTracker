# DisciplineTracker

DisciplineTracker is a personal productivity and discipline-building iOS app designed to help users organize their daily tasks, build consistent habits, and track their progress over time.

The project is being developed with Swift and SwiftUI, with a focus on a clean, modern interface and reliable task management.

## About

The idea behind DisciplineTracker is to create a simple system for planning and following daily activities such as workouts, meals, work, sleep, and other personal goals.

The application is designed around the idea that consistency is easier to maintain when daily activities are clearly planned, tracked, and measurable.

## Current Features

* Create and manage tasks
* Task categories
* Task start time
* Task notes

* Task detail view
* Countdown to upcoming tasks
* Overdue task indication
* Local notifications
* Persistent data storage with SwiftData
* Animated progress ring

## Project Structure

The application is being developed using separate SwiftUI views and components.

Main components currently include:

* `ContentView` — main application screen and task management
* `TaskCardView` — reusable task card component
* `TaskDetailView` — task details and task status information
* `AddTaskView` — task creation
* `TaskItem` — SwiftData model representing a task
* `NotificationManager` — local notification management
